# JOR-V3.1 Visualization Suite

This directory contains the visualization engine for the James Orion Report (JOR) Framework. These tools convert Bayesian posterior data into tactical safety intelligence.

## Requirements
To run these visualization scripts, ensure you have the following Python libraries installed:
- `pandas`
- `matplotlib`
- `seaborn`
- `numpy`
- `scikit-learn` (specifically for calibration curves in the safety audit)

Install all requirements via:
```bash
pip install pandas matplotlib seaborn numpy scikit-learn
